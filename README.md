# DeltaUserJS Plugins & Modules Repository 🧩

Kumpulan modul resmi dan komunitas untuk **[DeltaUserJS](https://github.com/kotakbiasa/DeltaUserJS)** (mtcute Layer 229 Userbot).

## 🚀 Cara Memasang Modul

Anda dapat memasang modul apa pun langsung ke userbot Anda dengan salah satu cara berikut:

### 1. Via Master Bot (Deep Link)
Klik tombol pemasangan di channel katalog **[@PluginList](https://t.me/PluginList)** atau buka langsung di bot:
```text
https://t.me/PanelDeltaUbot?start=install_<nama_modul>
```
*Contoh:* `https://t.me/PanelDeltaUbot?start=install_wiki`

### 2. Via Perintah Userbot
Ketik perintah berikut di obrolan mana saja melalui akun userbot Anda:
```text
.install <nama_modul>
```
*Contoh:* `.install wiki` atau `.install brat`

Atau pasang langsung dari file URL raw:
```text
.install https://raw.githubusercontent.com/kotakbiasa/DeltaUserJS-Plugins/main/tools/brat.ts
```

## 📂 Struktur Direktori

```text
├── group/        # Modul manajemen dan otomasi grup Telegram (antiflood, welcome, tagall, dll.)
├── system/       # Utilitas sistem dan diagnostik (speedtest, sysinfo, stats, sessions, dll.)
├── tools/        # Alat media grafis & kreasi (brat, carbon, qr, convert, tourl, dll.)
└── util/         # Utilitas harian & informasi (wiki, weather, gempa, calc, purge, afk, dll.)
```
